Para o conceito, consolidei a identidade do Anirium em uma base escura premium, usando o marfim e o dourado do mascote como assinatura — sem cair no padrão roxo/neon comum em plataformas de anime.
A paleta-base que eu adotaria como padrão é: Preto Profundo #0B0B0D para o fundo principal; Grafite #1A1A1F e Carvão #23232A para superfícies/cards; Cinza Quente #3A3A43 para bordas; Marfim #FFF9F0 como texto principal e ligação direta com o mascote; Bege Quente #EADCC8 para texto secundário; Dourado #FFC766 como cor de destaque; e Âmbar #FFB347 como acento mais intenso, especialmente em estados ativos, brilhos e CTAs.
O conceito da home segue uma lógica importante: o mascote e o dourado são elementos de identidade, mas não devem transformar toda a interface em dourado. A UI permanece predominantemente preta/grafite; o dourado aparece seletivamente em navegação ativa, botões importantes, estrelas, nós, conexões e elementos relacionados à genealogia.
A composição que desenhei também começa a criar uma linguagem própria para o produto: nó → linha orbital → nó → obra, fazendo com que a ideia de genealogia de franquias apareça visualmente pela interface inteira. Isso pode virar um dos elementos mais reconhecíveis do Anirium, junto do mascote e do A.
Para a home, eu seguiria essa hierarquia: Header → Hero/identidade → atalhos dos pilares → Destaques da Semana → gêneros → franquias populares → calendário de transmissão → conteúdo editorial/comunidade. Isso deixa a primeira tela bonita, mas ainda comunica rapidamente o que o Anirium realmente faz.
